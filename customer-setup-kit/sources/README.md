# NTZ Recruiting Copilot — Customer Setup Kit

Welcome. This kit helps your IT or Talent Acquisition / HR Operations admin set up NTZ Recruiting Copilot in your Microsoft 365 tenant.

## Read first

1. **Customer-Setup-Guide.docx** — Step-by-step 15-minute walkthrough
2. **IT-Admin-Runbook.docx** — One-page reference card for ongoing admin tasks

## Templates to customize and upload

## Prerequisites

- Microsoft 365 Copilot license assigned to each user of NTZ Recruiting Copilot
- SharePoint Online site (or use OneDrive)
- Admin permission to upload documents
