# NTZ Recruiting Copilot — IT Admin Runbook

One-page reference card for ongoing administration

---

## Common admin tasks

| Task                     | How to do it                                                                                              |
| ------------------------ | ---------------------------------------------------------------------------------------------------------- |
| Add a new user           | Assign Microsoft 365 Copilot license + grant SharePoint Read on Playbooks folder                          |
| Update the playbook      | Edit hiring-playbook.docx in SharePoint; changes propagate within 30 min (SharePoint indexing)            |
| Onboard a new department | Add their SharePoint site URL to the Playbooks library OR copy the playbook to their site root            |
| Remove a user            | Reassign or remove their Copilot license                                                                  |
| Audit usage              | Microsoft 365 Admin Center → Reports → Microsoft 365 Copilot usage                                        |

---

## When to escalate to Netsmartz

- Agent returning wrong or hallucinated content consistently
- Need to integrate with non-Microsoft systems (Workday, Greenhouse, Lever, etc.)
- Need to customize the system prompt itself (not available in v1.0; requires consulting engagement)
- Sensitive requisitions (executive search, confidential restructuring) requiring extra security controls

## Discovery file names (must match exactly)

- hiring-playbook.docx

- jd-template.docx
- interview-kit-template.docx
- scorecard-template.docx
- outreach-template.docx

Place in a folder named **Playbooks** or **Templates** (case-insensitive) accessible to all users.
